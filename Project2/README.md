The central objective of this project is to establish our own Neural network. In doing so, we will study both classification and regression problems by developing our own feed-forward and backpropagation Neural network code. Furthermore, we will compare our results and analysis with the first project. We will use the MSE functions, their derivatives, with and without penalties---where the parameters will be a list of weights and biases of Neural network trainable arrays. So the penalties are not the theta parameters anymore but the weight matrices w^(l) for Neural Networks.
